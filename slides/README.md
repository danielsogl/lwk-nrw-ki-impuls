# Slides

Deck zum Impuls „KI für Entwickler:innen: Produktiver mit Angular und Spring Boot“,
gebaut mit [Slidev](https://sli.dev) auf dem SHI-Template.

```bash
npm install
npm run dev          # http://localhost:3030, Presenter-Ansicht mit Taste „P“
npm run build        # statische Seite nach dist/
npm run export       # PDF
```

`slides.md` enthält Titel, Agenda und Abschluss, die Kapitel liegen in `pages/`.
Die Presenter-Notes (HTML-Kommentare am Folienende) enthalten Zeitplan, Demo-Prompts,
Quellen und Prüfhinweise.
